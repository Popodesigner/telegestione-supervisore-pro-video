# Supervisore Pro — sito promozionale

Landing page statica e indipendente del progetto **Telegestione Supervisore Pro**.

- Sito pubblico: <https://popodesigner.github.io/telegestione-supervisore-pro-video/>
- Demo applicativa: <https://techai.altervista.org/supervisore-v3-test/index.html>
- Repository principale: <https://github.com/Popodesigner/telegestione-supervisore-pro>

Il sito è composto esclusivamente da HTML, CSS, JavaScript e risorse multimediali statiche. Può essere pubblicato su GitHub Pages, Altervista o qualsiasi hosting web tradizionale senza Node.js e senza database.

Per Altervista, caricare il contenuto della repository nella cartella `/telegestione-supervisore-pro-video/` del proprio spazio web.
